# Sharekite

Sharekite publishes the web pages, reports, and static sites that your agent makes, and shares them with clients, partners, and collaborators. This plugin connects your agent to the Sharekite MCP server at `https://studio.sharekite.app/mcp` and adds the `publish-and-share` skill, which tells the agent when to use Sharekite and which tools to use for each job.

## Use it

Ask your agent to put work online, for example: "Publish this report and give me a link I can send." The agent uploads the files as a new version and gives you a preview link. The work goes online only when you ask. You choose who can open it: anyone with the link, anyone with a password, or only the people you name, who receive an email invitation.

Later, ask the agent to publish a new version at the same address, to check who can open a page and the status of each invitation, or to find work with changes that are not published.

Before the agent can use the tools, you connect Sharekite and sign in to your Sharekite account in the browser. Setup steps for each agent are on the [setup page](https://www.sharekite.app/connect/).

## Data

The plugin sends the files that you ask the agent to publish, the project names, and the audience that you choose, including the email addresses of the people you name, to your Sharekite account. Sharekite hosts the files and sends the invitation emails. The plugin runs no code on your computer: it contains the server address, the skill, and the icons. The [privacy policy](https://www.sharekite.app/privacy/) describes how Sharekite handles your data.
